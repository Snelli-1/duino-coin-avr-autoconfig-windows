# Security Policy

## Támogatott verzió

Mindig a legfrissebb GitHub Release támogatott.

## Sérülékenység jelentése

Ne nyiss nyilvános hibajegyet olyan jelentéshez, amely mining key-t, személyes
adatot vagy kihasználható sérülékenységet tartalmaz. Használd a GitHub
"Report a vulnerability" privát bejelentési lehetőségét.

## Titkok

Soha ne commitold a `Setup_Settings.txt`, `Settings.cfg`, `.bak` vagy EXE
fájlokat. Ezeket a `.gitignore` alapból kizárja.
